Booking Access

Wix Button vs. Direct Mews Link

Wix “Book Now” Button
Guest clicks button
↓
Browser loads the Wix page and button code
↓
Wix sends the guest to Mews

A previously cached version of the Wix page, button or destination may continue sending some repeat visitors through an outdated path even after the published website has been updated.

Direct Mews Link
Guest clicks or pastes link
↓
Browser opens Mews directly

This removes the Wix page and its cached button code from the path, allowing the guest to reach the current Mews Booking Engine directly.

Recommendation: Keep the branded “Book Now” buttons on the Crescent Hotel website, but also retain the full direct Mews Booking Engine link as a backup. If someone has trouble opening the Booking Engine through the website on their personal browser, send that person the direct link. It may not look as polished as the website button, but it provides the shortest and most dependable route to the booking page while bypassing that browser’s cached Wix page or button.
