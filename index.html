Booking Access

Wix Button vs. Direct Mews Link

``` ```
Wix “Book Now” Button
Guest clicks button
↓
Browser loads Wix page and button code
↓
Wix sends the guest to Mews

A previously cached version of the Wix page, button or destination may continue sending some repeat visitors through an outdated path even after the published site has been updated.

Direct Mews Link
Guest clicks or pastes link
↓
Browser opens Mews directly

This removes the Wix page and its cached button code from the path, allowing the guest to reach the current Mews Booking Engine directly.

Temporary recommendation: Provide guests with the full direct Mews Booking Engine link. It is not as polished as a branded website button, but it is the most dependable way to bypass Wix-related cache or cookie issues until a cleaner permanent booking connection can be created and thoroughly tested.
