Booking Access

Wix Button vs. Direct Mews Link

Wix “Book Now” Button
Guest clicks button
↓
Browser loads the Wix page and button code
↓
Wix sends the guest to Mews

A previously cached version of the Wix page, button or destination may continue sending some repeat visitors through an outdated path even after the published website has been updated.

Direct Mews Link
Guest clicks or pastes link
↓
Browser opens Mews directly

This removes the Wix page and its cached button code from the path, allowing the guest to reach the current Mews Booking Engine directly.

Recommendation: Keep the branded “Book Now” buttons on the Crescent Hotel website, but also retain the full direct Mews Booking Engine link as a backup. If someone has trouble opening the Booking Engine through the website on their personal browser, send that person the direct link. It may not look as polished as the website button, but it provides the shortest and most dependable route to the booking page while bypassing that browser’s cached Wix page or button.
Booking Access

Two Paths to the Mews Booking Engine

Both options can reach the same destination. The Wix button simply adds an extra website layer that a guest’s phone or laptop may have cached.

Wix “Book Now” Button
button.onClick(() => {
  open("MEWS_BOOKING_URL");
});
↓
1. The device loads the Wix website.
↓
2. Wix loads and runs the button’s saved destination.
↓
Possible trouble point: That device may still be loading an older cached version of the Wix page or button destination.
↓
Destination:
Mews Booking Engine
Direct Mews Link
https://app.mews.com/distributor/…
↓
1. The guest clicks or pastes the current Mews link.
↓
Destination:
Mews Booking Engine
The difference: The guest goes straight to Mews without first relying on the Wix page and its saved button code.
Best current approach: Keep the attractive Wix booking buttons and also provide the full direct Mews Booking Engine link as a backup. If someone has trouble on a personal phone or laptop, send the direct link so they can bypass that device’s cached Wix path.
Website Appearance

Why the Full Mews URL Is Usually Hidden

The direct Mews link can be placed visibly on the website, but it is long, technical-looking and unattractive. Normally, the exact same link is placed behind a clean button so guests see a simple instruction instead of the full URL.

```
Visible Direct Link
``` https://app.mews.com/distributor/long-booking-engine-address

It works, but looks technical and can be difficult to read, remember or tap.

The Same Link as a Button
BOOK A ROOM

The Mews URL is still underneath the button, but the guest sees a clear, attractive action.

Important: The button and visible URL can point to the exact same Mews address. The button is used because it looks better—not because it is a different type of link. The full URL should still be kept available as a backup for anyone whose browser is having trouble with the Wix page or button.
